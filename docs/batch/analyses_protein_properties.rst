Protein Properties
==================

The properties of a :class:`~sparrow.protein.Protein` that ``sparrow.batch``
can compute. A property takes no arguments, so each is named on its own -
``"FCR"`` - and read back as ``protein.FCR``. The 20 scalar properties of
:data:`sparrow.properties.PROPERTY_NAMES` are computed for the whole batch at
once; :doc:`../protein/index` explains each of them.
