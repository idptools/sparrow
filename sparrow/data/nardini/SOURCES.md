# NARDINI+ / GIN reference data

This directory holds published reference data used by `sparrow.nardini`. None of it was generated by sparrow — it is redistributed from the GIN resource, and if you use it you must cite the original work.

## Files

### `gin_centroids_human_v1.npz`

The 30 GIN cluster centroids: a 30 × 90 matrix in sparrow's canonical NARDINI+ feature order (36 patterning features followed by 54 compositional features). Obtained by k-means (k=30) on the NARDINI+ z-score vectors of human IDRs of length 100–300, with z-scores clipped to ±3.

Keys: `feature_names`, `clusters`, `centroids`, `format_version`, `metadata_json`.

### `gin_cluster_definitions_human_v1.csv`

Human-readable description of each cluster plus the number of human IDRs assigned to it (24,508 in total). Columns: `cluster`, `description`, `num_idrs`.

### `gin_composition_prior_<species>_v1.npz`

Published per-species compositional backgrounds — the mean and standard deviation of each of the 54 compositional features across that species' IDRome (IDRs ≥ 30 residues). Stored in sparrow's `NardiniBackground` archive format, so they load directly via `NardiniBackground.load()` or `load_reference_background(species)`.

Available species keys: `human`, `mouse`, `rat`, `xenopus`, `fly`, `zebrafish`, `yeast`, `worm`, `arabidopsis`.

`num_sequences` is stored as `-1` because the published tables do not report how many IDRs went into them; `NardiniBackground.num_sequences` therefore reads as `None` for these.

## Regenerating

```bash
python devtools/scripts/build_nardini_reference_data.py
```

That script re-downloads from the canonical locations and **verifies that the feature ordering still matches** sparrow's `COMPOSITION_FEATURE_NAMES` and `patterning_feature_names('8')` before writing anything, so a silent upstream reordering cannot corrupt the bundled data.

## A note on `W Patch`

sparrow's compositional feature set has 54 entries and deliberately contains no `W Patch` feature, matching these published tables. This is not an oversight. The original GIN pipeline did compute a tryptophan patch feature — its mean and standard deviation across the whole human IDRome are both exactly `0.0` (see `general_data/sapiens_full_idrome_gte_30_compositional_mean.npy` in the source repository, which has 55 entries). Tryptophan patches simply do not occur, so the feature carries no information and was dropped. Adding it back would break compatibility with these centroids and priors.
